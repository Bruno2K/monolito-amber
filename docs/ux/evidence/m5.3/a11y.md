# M5.3 accessibility notes

Figma nodes `264:8540` (a11y), `264:8332` (states), `264:8436` (narrow 1180×820).

## Keyboard and focus

- Global skip link and shell landmarks are unchanged.
- Calendar projections use a tablist (Mês / Semana / Dia / Agenda) with `aria-selected`.
- Date cells, hour slots and event chips are buttons with names that include date and/or time plus the event title.
- Event editor and revoke/role confirmations are `role="dialog"`. Escape closes the editor and restores the previously focused control (`useInspectorEscape`).
- Share revoke/role confirmations return focus to the triggering button.

## Names and semantics

- Hub cards expose calendar name plus ownership/access provenance (owner, direct grant, inherited team).
- Referenced events are announced as referenced Task/Milestone/Deliverable/Gate and stay read-only.
- Unauthorized calendars and omitted referenced sources do not render a name, count, timing or color chip.
- Status and errors use `aria-live` (`polite` for loading, `assertive` for error/denied/revoked).

## Contrast and motion

- Reuses Amber tokens (sidebar `#0f1115`, amber focus `#d97706`, body text `#111827` on `#f9fafb` / white cards).
- Focus is a 2px amber outline (`:focus-visible`).
- `prefers-reduced-motion: reduce` disables calendar skeleton and chrome transitions.
- Month/week grids keep a minimum column width and horizontal scroll at 1180×820 instead of compressing labels.

## States (R11)

Initial empty, filtered empty, loading skeleton, recoverable error, no-permission, revoked deep link, inactive-owner freeze copy, and archived read-only are implemented in `CalendarStates` (`data-state` + node `264:8332`).

## Axe

Local RC `e2e/local-rc/a11y.spec.ts` includes `/calendars` and `/calendars/schedule`. Serious/critical violations fail the job.
