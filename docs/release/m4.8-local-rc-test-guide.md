## Zero → golden path

Requires Node 22, pnpm 10, Docker, curl. Windows: [WSL2 path](../development/m3-windows-local-rc.md).

```bash
cp .env.example .env          # placeholders only — never paste live cloud secrets
pnpm local-rc:bootstrap       # postgres+minio, full migration chain, AMBER_SEED_M3=1 (M3 + M4 fixtures)
pnpm local-rc:up              # API :3001 + web :3000
pnpm local-rc:health          # /health and /ready show commit SHA
pnpm local-rc:e2e             # Playwright vs real stack (1440×900 and 1180×820)
```

Stop apps (keep data plane): `pnpm local-rc:down`

Full wipe + re-seed: `pnpm local-rc:reset`

Upgrade rehearsal (drop → migrate → M3/M4 seed → insert pre-M4 Task → re-seed → assert IDs):

```bash
pnpm local-rc:rehearse-reset
# or the documented twin:
pnpm local-rc:rehearse-upgrade
```

## Golden path (manual)

1. Open Planejamento (Lista). Filter `Seed outline programme`.
2. Nova Tarefa → assign Seed Contributor A → Iniciar.
3. Add a FINISH_TO_START predecessor to a new successor; Iniciar on the successor stays blocked.
4. Complete the predecessor; successor can start.
5. Gantt: edit successor dates; successors/parents are not shifted.
6. Marcos: a late linked Task explains `LINKED_TASK_LATE` / AT_RISK. Stored status stays PLANNED until Alcançar.
7. Entregas → `DEL-ARCH-001`: Tarefas / Marcos appear as authorized refs. Deliverable owner/status do not change.

## Recovery / reset

1. `pnpm local-rc:reset` — compose `down -v`, wipe `.data`, migrate + seed.
2. `pnpm local-rc:rehearse-reset` — drop → migrate → seed → pre-M4 insert → re-seed → deterministic IDs.
3. Previous SHA: `git checkout <sha>` then reset. There is **no** cloud image to roll back.
