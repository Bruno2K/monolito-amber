## Topology (service names + host ports)

| Service | How it runs | Host port | Notes |
| --- | --- | --- | --- |
| `postgres` | Compose (default) | 5432 | User/db `amber` / password placeholder `amber` |
| `minio` | Compose (default) | 9000 API, 9001 console | Image `bitnamilegacy/minio` (MinIO server; Docker Hub `minio/minio` was removed). Placeholders `amberminio` / bucket `amber-files` via `MINIO_DEFAULT_BUCKETS` |
| `api` | Host `pnpm --filter @amber/api start:dev` **or** Compose profile `apps` | 3001 | Bind `0.0.0.0` |
| `web` | Host `pnpm --filter @amber/web dev` **or** Compose profile `apps` | 3000 | Rewrites `/api` → API |
| `redis` | **Not started** | 6379 | Profile `jobs` only |

Files persist through MinIO (`S3_ENDPOINT` / `S3_BUCKET`, `AMBER_REQUIRE_S3=1`). `OBJECT_STORAGE_DIR` is not the live Local RC adapter.

## Zero → golden E2E (host apps — recommended)

Requires Node 22, pnpm 10, Docker, curl. On Windows use the [WSL2 path](./m3-windows-local-rc.md) (native Next.js is not supported).

```bash
cp .env.example .env          # local placeholders only; never paste live cloud secrets
pnpm local-rc:bootstrap       # compose postgres+minio, migrate, AMBER_SEED_M3=1 seed
pnpm local-rc:up               # API :3001 + web :3000
pnpm local-rc:health           # /health and /ready show commit SHA
pnpm local-rc:e2e              # Playwright vs real stack (both 1440×900 and 1180×820)
```

Stop apps (keep data plane): `pnpm local-rc:down`

Full wipe + re-seed: `pnpm local-rc:reset`

### Equivalent Compose apps profile

After bootstrap (so migrations/seed have run **on the host** against `localhost:5432`):

```bash
GIT_SHA="$(git rev-parse HEAD)" docker compose --profile apps up -d --build
```

Inside the `api` container, `DATABASE_URL` points at service `postgres`. Do not start Redis.

## Migration + seed

```bash
pnpm prisma:generate
pnpm prisma:migrate
AMBER_SEED_M3=1 pnpm prisma:seed
```

Catalog seed is always applied. `AMBER_SEED_M3=1` writes the synthetic M3 dataset (two orgs, roles, Phase/Deliverable/WorkPackage, team-only member). Idempotent upserts on a disposable database.

## Health, readiness, logs

```bash
curl -s http://127.0.0.1:3001/api/v1/health
curl -s http://127.0.0.1:3001/api/v1/ready
curl -sD - -o /dev/null -H 'x-correlation-id: bruno-local-rc' http://127.0.0.1:3001/api/v1/auth/session
```

- **health**: process liveness + `commit` (`GIT_SHA` / `GITHUB_SHA`) + `build`
- **ready**: same identity plus Postgres `SELECT 1` (`database: skipped` when `SKIP_DB=1`)
- **logs**: JSON pino on stdout (`level`, `service`, `correlationId`, `method`, `path`, `status`, `ms`). Health/ready are quiet. Host logs: `.data/local-rc/api.log`
- Pass `x-correlation-id`; the API echoes it on the response.

## Reset / rollback (local)

1. `pnpm local-rc:reset` — compose `down -v`, wipe `.data`, migrate + seed again.
2. `pnpm local-rc:rehearse-reset` — migrate reset + seed + deterministic ID assertion (CI Local RC step; log under `docs/development/m3-rc1-evidence/reset-rehearsal.log`).
3. To return to a previous git SHA: `git checkout <sha>` then reset. There is no cloud image to roll back.

## Known limitations

- Worker/Redis off; no async scan/email jobs.
- Local cookies are not `Secure` (HTTP loopback).
- Foundation CI uses Testcontainers for API integration (including a MinIO container for the live adapter test); Local RC E2E is the `local-rc` job plus this runbook.
- Mock Playwright remains for fast UI iteration; it is not homologation evidence.
- Windows native Next.js is not the supported path; see [m3-windows-local-rc.md](./m3-windows-local-rc.md).
