- `reason` / `blockers` are extras on existing `PLANNING_STATE` problem+json — no new permission codes and no new HTTP `code` family.
- No Prisma migration. `planning.task_dependencies` already had UNIQUE pair, not-self CHECK, tenant trigger, and indexes.
- Task-scoped history now also includes `task_dependency` events when this Task is either end.
