## R03 — Phase / Deliverable / WorkPackage / Issue / ProjectMembership + read-links

### Phase — owner Operations

Implemented M3.3. Fields/states: [m3-project-operations-contract.md](./m3-project-operations-contract.md). APIs under `/api/v1/projects/:projectId/phases`. Reads: `project.read`. Mutations: `phase.create|update|complete`. Dates do **not** transit status. Planning may **link** `Task.phaseId` / `Milestone.phaseId` (same Project). Completing a Task does not complete a Phase.

### Deliverable — owner Operations

Implemented M3.4. Deliverable ≠ Document. Required `phaseId` + `disciplineId`. Ownership XOR. Delivery rule is WorkPackage-based, **not** Task-based. Optional `Task.deliverableId` / `Milestone.deliverableId` are context. `operations.deliverable_documents` is Document evidence, not a Planning table.

### WorkPackage — owner Operations

Implemented M3.5. WorkPackage ≠ Task. Own machine (`PLANNED → ACTIVE ↔ BLOCKED → DONE`). Incidental Task links do **not** block WP `DONE` (`incidentalTasksBlockWorkPackageDone() === false`). Optional `Task.workPackageId` is context.

### Issue — owner Coordination

PF-1.4. Issue ≠ Task. Optional `Task.issueId`. Issue → 0..N Tasks. Completing Tasks does not resolve or close the Issue (integration + `taskCompleteCascadesToIssue() === false`).

### ProjectMembership — owner Identity / Project

PF-1.2. `ACTIVE → SUSPENDED | REMOVED`. ACTIVE OrgMembership required for ACTIVE ProjectMembership. Task assignment requires ACTIVE Project + Org membership. TeamMembership ≠ ProjectMembership. Owner / Team / Discipline never grant Project access. Immediate revoke: removed/suspended sessions cannot read Planning rows (omit-not-leak).

### Hub / Governance read-links (not Planning ownership)

- M3.6 Hub `upcomingMilestones` reads `planning.milestones` as a **derived signal**. Hub is not a second planner (`api/src/operations/hub.service.ts`).
- Governance `PlanningGovernanceAdapter` reads Planning and **must not** mutate it.
- M3.7 context endpoints on Deliverable/WorkPackage may list linked Tasks/Milestones; each read re-authorizes.

### Seed on this tip

`prisma/seed.ts` + `prisma/m3-seed.ts` cover orgs, memberships, Operations fixtures. **No** dedicated Planning Task/Milestone seed dataset exists yet. Additive Local RC Planning fixtures are planned in [m4.1-migration-seed-rollback-plan.md](./m4.1-migration-seed-rollback-plan.md) (M4.8), not applied here.
