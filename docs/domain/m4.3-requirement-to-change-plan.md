## Explicit lifecycle surface (additive; existing `POST …/status` remains)

| Command | Path | Permission | Body | From → to |
| --- | --- | --- | --- | --- |
| Start | `POST …/tasks/{id}/start` | `task.update` | `{ expectedVersion }` | `TODO` or `BLOCKED` → `IN_PROGRESS` |
| Block | `POST …/tasks/{id}/block` | `task.update` | `{ expectedVersion, blockedReason }` | `IN_PROGRESS` → `BLOCKED` |
| Unblock | `POST …/tasks/{id}/unblock` | `task.update` | `{ expectedVersion }` | `BLOCKED` → `IN_PROGRESS` |
| Complete | `POST …/tasks/{id}/complete` | `task.complete` | `{ expectedVersion }` | `IN_PROGRESS` → `DONE` |
| Cancel | `POST …/tasks/{id}/cancel` | `task.update` | `{ expectedVersion }` | `TODO` \| `IN_PROGRESS` \| `BLOCKED` → `CANCELLED` |

All five require `Idempotency-Key`. Field PATCH cannot send `status`.
