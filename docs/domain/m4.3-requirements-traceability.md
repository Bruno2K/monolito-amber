## Honest deltas (not BLOCKER)

- Dedicated command paths (`/start` `/block` `/unblock` `/cancel`) are additive wrappers over the frozen `POST …/status` machine. `POST …/status` remains.
- Missing `expectedVersion` may surface as Nest validation 400 when omitted from JSON, or `PLANNING_STATE` 409 from the service. Both fail closed.
- Task-scoped history uses `project.read`, not `organization.read_audit`. It only returns that Task’s events.
- Inspector lives in `TaskInspector.tsx` (extracted from M4.2 inline read-only panel).
- No Prisma migration. No new permission codes.
