## Payload (normative, from contract §Single Planning read-model)

```
PlanningReadModel {
  projectId
  organizationId
  generatedAt
  view                  // echo of projection hint
  tasks: PlanningTaskRead[]      // TasksService.toDto + late + kanbanColumn + previews
  milestones: PlanningMilestoneRead[]  // MilestonesService.toDto (recordedStatus + derived status)
  dependencies: PlanningDependencyRead[]
  page: { page, pageSize, total, sort, order }
  counts: { total, late, byStatus }   // authorized + current filters only
  inspected: PlanningTaskRead | null  // ?inspect=; null if unauthorized (no title leak)
}
```

`kanbanColumn` derivation (gap analysis — **not** a stored column):

| Column | When |
| --- | --- |
| `PLANEJADAS` | stored `TODO` and `late === false` |
| `EM_ANDAMENTO` | stored `IN_PROGRESS` and `late === false` |
| `EM_RISCO` | stored `TODO` or `IN_PROGRESS` and `late === true` |
| `BLOQUEADAS` | stored `BLOCKED` (late or not) |
| `null` | stored `DONE` or `CANCELLED` |
