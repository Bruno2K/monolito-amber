## Column map (frozen; already in `deriveKanbanColumn`)

| Figma column | Stored status | Derived `late` | Class |
| --- | --- | --- | --- |
| PLANEJADAS | `TODO` | false | derived projection |
| EM ANDAMENTO | `IN_PROGRESS` | false | derived projection |
| EM RISCO | `TODO` or `IN_PROGRESS` | true | derived view — **not** a Task status |
| BLOQUEADAS | `BLOCKED` | any | stored status (late+BLOCKED stays here) |

## Move → command map (not a new machine)

| From (projection) | To | Command | Permission |
| --- | --- | --- | --- |
| PLANEJADAS or EM RISCO (`TODO`) | EM ANDAMENTO | `POST …/start` | `task.update` |
| EM ANDAMENTO or EM RISCO (`IN_PROGRESS`) | BLOQUEADAS | `POST …/block` + `blockedReason` | `task.update` |
| BLOQUEADAS | EM ANDAMENTO | `POST …/unblock` | `task.update` |
| Any | EM RISCO | **Reject** `KANBAN_DERIVED_COLUMN` | — |
| EM RISCO / PLANEJADAS (`TODO`) | PLANEJADAS when still late | **Reject** `KANBAN_DATE_SHIFT_REQUIRED` (would require editing due date) | — |
| `TODO` | BLOQUEADAS | **Reject** — forbidden skip | — |
| `IN_PROGRESS` / `BLOCKED` | PLANEJADAS | **Reject** — no return to TODO | — |
| Same column | same | no-op | — |
| `IN_PROGRESS` | (menu only) Concluir | `POST …/complete` | `task.complete` |
