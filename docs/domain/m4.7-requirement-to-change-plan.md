## Documented AT_RISK / MISSED inputs (no invented thresholds)

| Derived `status` | When (authorized visible inputs only) |
| --- | --- |
| ACHIEVED | stored ACHIEVED (always wins) |
| CANCELLED | stored CANCELLED (always wins) |
| MISSED | still PLANNED and `targetDate` is in the past |
| AT_RISK | still PLANNED, target not past (or null), and ≥1 visible linked Task is `late` **or** stored `BLOCKED` **or** FS dependency-start-blocked |
| PLANNED | otherwise |

`incomplete` in R05 names the contributing set (status not DONE or CANCELLED). An on-time, unblocked, un-gated incomplete Task is **not** enough to derive AT_RISK — that would invent a remaining-work policy ADR-016 forbids.
